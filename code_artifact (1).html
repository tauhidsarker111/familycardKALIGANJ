GitHub Pages-এর জন্য রেডি index.html ডাউনলোড করুন

উপরে আপনার Google Apps Script URL সেভ করার পর এই বাটনে ক্লিক করলে আপনার গুগল ডেটাবেস URL এম্বেড করা একটি সম্পূর্ণ index.html ডাউনলোড হবে। এটি সরাসরি GitHub Pages-এ আপলোড করলে যেকোনো ভিজিটর লাইভ ডেটা দেখতে পারবে!

সেটআপ নির্দেশিকা ও সম্পূর্ণ Google Apps Script (Code.gs)

  1. ধাপ ১ (Create Sheet): আপনার Google অ্যাকাউন্টে নতুন একটি Google Sheet খুলুন (যেমন: Kaliganj Family Card DB)।
  2. ধাপ ২ (Paste Code.gs): মেনু থেকে Extensions → Apps Script ওপেন করে আগের কোড মুছে নিচের Code.gs পেস্ট করে Save করুন।
  3. ধাপ ৩ (Deploy Web App): Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy ও Authorize করুন।
  4. ধাপ ৪ (Connect & Upload): প্রাপ্ত Web App URL কপি করে উপরে পেস্ট করে সংযোগ পরীক্ষা ও সেভ করুন ক্লিক করুন, তারপর Download Ready index.html নিয়ে GitHub-এ আপলোড করুন।
